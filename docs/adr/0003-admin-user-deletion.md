# 管理画面からのユーザー削除方針

管理画面のユーザー削除は、指定メールアドレスの勤怠・設定・会社日・連携関係・未承認申請を原子的に完全削除する。連携所有者を削除する場合は所有者のカレンダーだけを削除し、メンバーの連携前データを残して単独カレンダーへ戻す。連携メンバーを削除する場合はメンバー自身の休眠データと連携だけを削除し、所有者のカレンダーは残す。削除は現在ログイン中の管理者自身には許可せず、別の管理者の `ADMIN_EMAILS` 設定は変更しない。この境界により、削除対象のデータを消去しながら、別ユーザーの個人データや認証・権限設定を誤って消去しない。
